# 프로필 사진 폴더 (Profiles)

이 폴더에 사용자 이름과 동일한 파일명으로 사진을 넣어주시면 개인 주문 상세 카드의 뱃지에 사진이 자동으로 표시됩니다.

### 사용 방법:
- **파일명 형식**: `이름.확장자`
- **지원 확장자**: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`
- **예시**:
  - `정성재.jpg`
  - `정소윤.png`
  - `최미순.jpeg`

### 💡 권장 사진 규격:
| 항목 | 권장 사양 | 설명 |
| :--- | :--- | :--- |
| **비율** | **1:1 (정사각형)** | 인물이 정중앙에 위치한 구도가 가장 자연스럽습니다. |
| **해상도** | **120 × 120 ~ 200 × 200 px** | 실제 표시 크기는 44×44px이며, 고해상도(레티나/모바일) 화면에서 선명하게 보입니다. |
| **용량** | **100KB 이하 권장** (최대 500KB 이내) | 웹 실시간 렌더링(Base64) 특성상 용량이 작을수록 로딩 및 반응 속도가 빠릅니다. |
| **포맷** | **JPG / JPEG / WebP** | 인물 사진의 경우 압축률이 우수한 JPG 또는 WebP를 추천하며, 배경 투명도가 필요하면 PNG를 사용하세요. |

### 안내:
- 사진이 없는 사용자는 기존처럼 이름 두 글자 텍스트 뱃지로 자동 표시(Fallback)됩니다.
- 직사각형 사진도 중앙 기준(`object-fit: cover`)으로 자동 크롭되어 표시됩니다.
